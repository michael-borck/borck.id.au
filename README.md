# borck.id.au

Private launcher for everything Michael Borck — sites, books, tools,
research, simulations, decks, repos and profiles. `noindex`.

## Search portal

The page renders from `registry.js`, generated by:

```bash
python3 build-registry.py
```

This aggregates the existing inventories (Projects/README.md, tools
data, books manifest, GitHub via `gh`, research folders) and merges
curation from `overrides.yaml` (pinned cards, profiles, extra tags,
hide list). Re-run after shipping anything. Requires PyYAML.
